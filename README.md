# AI Task Control Keyboard

AI Task Control Keyboard is a Chinese input method project exploring compact keyboard layouts, shortcut-driven writing, and locally controlled language tooling.

This repository is the **public presentation layer** for the project. It contains product information, public documentation, and a release roadmap.

## Repository Boundary

The following remain private and are intentionally excluded:

- iOS application and keyboard-extension source code
- Core inference and product logic
- Model weights and production configurations
- Training corpora, staging data, and formal lexicons
- Internal training automation and operations consoles
- Apple signing material, provisioning profiles, and packaged app bundles

The private core is not distributed from this repository.

## Project Status

The project is in development alpha. The public materials are not an App Store download and do not represent a release candidate.

Current public goals:

- Make the compact keyboard workflow easier to understand
- Document the product direction and interaction model
- Share selected non-sensitive progress and release notes
- Keep the core implementation and production data under project-owner control
