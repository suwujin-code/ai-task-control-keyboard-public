# Roadmap

## Development alpha

- Stabilize the compact keyboard layout
- Improve shortcut-library editing and theming flows
- Validate keyboard behavior across real host applications
- Continue quality-controlled Chinese input evaluation

## Release preparation

- Complete signing and real-device verification
- Complete accessibility, rotation, stability, and privacy checks
- Prepare App Store metadata, support information, and review notes
- Publish only after the release gates are independently verified

## Public collaboration

- Share product direction and non-sensitive design decisions
- Collect feedback on workflows and documentation
- Keep proprietary code, models, and production data private
