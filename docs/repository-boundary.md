# Public and Private Boundary

## Public layer

The public repository may contain:

- Product positioning and non-sensitive feature descriptions
- Public interaction principles and roadmap items
- Screenshots or illustrations cleared for public use
- Release notes that do not expose internal paths, credentials, or training data
- Website copy and links to public project material

## Private layer

The private project retains:

- iOS application and keyboard-extension source
- Internal packages and product algorithms
- Training scripts, corpora, model artifacts, and evaluation data
- Factory dashboards, local automation, and operational logs
- Apple signing, provisioning, and release artifacts

Any file that crosses this boundary must be reviewed for secrets, personal data, third-party rights, internal URLs, and proprietary implementation detail.
