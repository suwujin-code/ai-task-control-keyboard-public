# AI Task Control Keyboard

## Short description

A compact Chinese input keyboard focused on fast task control, editable shortcuts, and a calmer writing workflow.

## Public project copy

AI Task Control Keyboard is a development-alpha iOS keyboard project for people who move between ordinary typing, reusable shortcuts, and AI-assisted work. The project emphasizes compact layout, direct editing, theme flexibility, and local control over the production pipeline.

The public project page documents the product direction and selected milestones. The application core, model assets, production lexicons, and training factory remain private.
